PERINATAL LOSS KEEPSAKE CREATOR - WEB / CHROMEBOOK VERSION 2.6 PWA
================================================================

Purpose
-------
A browser-based, Chromebook-friendly keepsake creator for Abington Jefferson Perinatal Loss Committee.
Designed to build a printable 8 x 10 keepsake from one, two, three, or four photos, with optional baby name and birthday text.

What this version includes
--------------------------
- Installable Chromebook PWA with in-app Install App button
- GitHub Pages-ready deployment package
- Offline cache updated for installed-app use
- Workflow order updated to: Layout, Photos, Adjust, Details, Review
- Smaller, more subtle baby name and birthday text
- Several readable font choices for the baby name and birthday
- Accurate visual layout icons in the layout picker
- Drag loaded photos directly inside the preview to reposition them
- Apply selected photo settings to all active photos
- Finish Review button now prints the keepsake
- Guided step-by-step workflow
- Layout thumbnails for easier selection
- Layouts for 1-photo, 2-photo, 3-photo, and 4-photo keepsakes
- Photo buttons directly inside empty preview frames
- Basic / Advanced editing split for easier use
- Print readiness checklist before printing
- Built-in committee logo in the header
- Checkerboard-style tilted logo tile in the workspace background (screen only)
- Live preview
- Per-photo controls:
  * Brightness
  * Contrast
  * Saturation
  * Hue
  * Warmth
  * Sharpness
  * Zoom
  * Horizontal position
  * Vertical position
  * Rotation
  * Crop
- Photo styles:
  * Color
  * Black & White
  * Sepia
- Baby's Name and Birthday fields included in the printed image
- Save final keepsake as JPG or PNG
- Print through the browser print dialog
- Photos are processed locally in the browser; no upload code is included

How to use
----------
1. Unzip the folder.
2. Open index.html in Chrome.
3. Follow the guided workflow:
   - Choose layout
   - Add photos
   - Adjust photos if needed
   - Enter baby details
   - Review readiness and print

Hospital privacy note
---------------------
This app is designed so photos are handled locally in the browser. A hospital should still review the app under its own privacy,
HIPAA, device management, records-retention, and clinical-workflow policies before production use.
