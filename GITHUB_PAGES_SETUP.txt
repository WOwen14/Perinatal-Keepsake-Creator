PERINATAL LOSS KEEPSAKE CREATOR - CHROMEBOOK PWA SETUP
======================================================

This folder is ready for GitHub Pages.

ONE-TIME GITHUB SETUP
---------------------
1. Sign in to GitHub.
2. Create a new PUBLIC repository. Suggested name:
      perinatal-loss-keepsake
3. On the new repository page, choose Add file > Upload files.
4. Upload the CONTENTS of this folder to the ROOT of the repository.
   Important: index.html must be at the repository root, not inside another folder.
5. Commit the files.
6. Open repository Settings > Pages.
7. Under Build and deployment:
      Source: Deploy from a branch
      Branch: main
      Folder: / (root)
   Click Save.
8. GitHub will publish the site. The address will normally be:
      https://YOUR-GITHUB-USERNAME.github.io/perinatal-loss-keepsake/

ONE-TIME CHROMEBOOK INSTALL
---------------------------
1. Open the published GitHub Pages address in Chrome on the Chromebook.
2. Wait a few seconds. An Install App button should appear in the top-right of the Keepsake Creator.
3. Click Install App and approve the installation.
4. Open the Chromebook Launcher and find Perinatal Loss Keepsake Creator.
5. Right-click the app icon and choose Pin to shelf.

NORMAL NURSE USE
----------------
Click the Keepsake Creator icon on the Chromebook shelf. No Files app or index.html is needed.

OFFLINE USE
-----------
After it has been opened successfully once from GitHub Pages, the core app files are cached on the Chromebook and the app can run without internet access.

PRIVACY
-------
The GitHub Pages site hosts only the application files (HTML, CSS, JavaScript, logo and icons). Baby photos selected by the nurse are processed locally in the Chromebook browser by this app. There is no photo-upload code in the Keepsake Creator.

UPDATES
-------
When a newer version is uploaded to the same GitHub repository, open the app while online. The service worker will refresh the application files. If the old version remains open, close and reopen the app.
